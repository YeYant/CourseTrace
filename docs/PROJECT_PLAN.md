# CourseTrace 项目计划

## 目标用户与问题

学生、助教与制作本地学习工具的开发者，经常需要核对一个知识点来自哪份资料的哪一页。
CourseTrace 提供「资料 → 页 → 原文 → 版本」之间可检查的联系。

## v0.1 的边界

先验证个人电脑上的 PDF 导入、文字检索、原页预览和引用导出。以原创示例演示全流程。
第一版独立于模型服务；后续学习助手可以调用本地检索接口。

## 技术结构

- Python 标准库 HTTP 服务：只监听 127.0.0.1，校验 Host、Origin 与写请求标识。
- PyMuPDF：在独立子进程中提取逐页文本和渲染页面，支持终止与超时。
- 任务队列：导入、重建与重定位后台执行，报告进度；数据库与文件提交使用短临界区。
- SQLite：保存资料元信息与页文本；更新索引时使用事务。
- HTML / CSS / JavaScript：零构建步骤，无远程字体、统计脚本或前端 CDN。

## 设计方向

蓝色索引标记与白色纸页，突出「找到出处」而非聊天界面。

配色：正文 #1A2D50、辅助字 #607089、主操作 #254CC9、页面底色 #F3F6FA、浅蓝 #E8EEF8、状态绿 #13786E。
字体：本地 Segoe UI / Microsoft YaHei UI；清晰的中文层级，不加载网络字体。
布局：左侧资料库、中间原文匹配结果、右侧可核对的 PDF 原页；窄屏依次堆叠。
检视：不使用无意义的统计卡片和宣传横幅，页面面积优先分给原文与原页。

## 下一阶段建议

1. 请几位真实用户导入他们有权使用的资料，收集检索失败和页码核对的问题。
2. 根据真实反馈改进断行、双栏、连字符检索，以及较大资料库的索引性能。
3. 再评估 OCR、可编辑的印刷页码映射、引用集合导出。
4. 经独立验证后，设计可供学习助手调用的稳定接口或 MCP 适配层。
