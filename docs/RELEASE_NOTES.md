# CourseTrace v0.1.0-alpha.1

从一个概念，回到它的原页。这是面向 Windows 的本地课程 PDF 源码预览版。

## 使用

解压全部文件，安装 Python 3.10+（本次实测 3.13），运行 `启动 CourseTrace.bat`。首次需联网安装依赖；使用时无需 AI API 或账号。建议先点击「打开示例资料」，完成检索、原页核对与引用导出。

## 升级与回滚

1. 关闭所有 CourseTrace 启动窗口，备份旧项目的整个 `data/`；外部跟踪文件另外备份。
2. 将旧 `data/` 复制到新版本文件夹。不要复制旧 `.venv`，由新启动器创建。
3. 首次打开旧格式数据库，程序先在 `data/backups/library-v0-*.sqlite3` 保存备份，再迁移托管路径与检索文本。
4. 移动项目后上传副本仍在 `data/files/`。外部原文件移动时点击「重新定位」；若内容不同，会先要求确认后重建索引。
5. 回滚到旧源码时，关闭程序并恢复升级前备份的**整个 data 文件夹**。数据库备份不含 PDF，不能代替完整资料备份；旧源码不认识新的相对路径格式。

## 已知限制

- 目前实测 Windows / Python 3.13 / Edge。CI 已配置 Windows Python 3.10、3.13；远程运行结果需要首次推送后确认。macOS / Linux 未实测。
- 当前是源码包，需要 Python；不提供独立 exe。
- 单文件 50 MB / 2000 页；单次解析最多 120 秒。复杂大文件可能需要拆分。
- 无 OCR、语义问答、印刷页码自动映射；公式、表格、上下标以原页为准。
- 仍会为候选文件核验哈希；不承诺大型资料库响应时间。每页显示最多 100 处命中。
- 任务状态保存在当前进程内；关闭程序会结束任务，重新启动后需要重新导入未完成资料。索引提交阶段不能取消。
- 移出记录保留 PDF 副本；可在完成备份后自行管理不用的副本。
